# Mass Effect: They Will Not Break Us

Top-down shooter / Wave Survival в сеттинге вселенной Mass Effect.

## Описание
Выживайте в руинах Лондона против сил Жнецов. Волны врагов становятся сложнее с каждой минутой.

## Управление
- **WASD** - Перемещение
- **Мышь** - Прицеливание
- **ЛКМ** - Стрельба
- **SPACE** - Перекат (уклонение)
- **ESC** - Выход/Пауза
- **ENTER** - Подтверждение (в меню)

## Запуск игры

```bash
cd /workspace
python src/main.py
```

Или через прямой вызов:
```bash
python -m src.main
```

## Структура проекта

```
src/
├── main.py                 # Точка входа
├── core/                   # Ядро игры
│   ├── config.py          # Конфигурация и константы
│   ├── game.py            # Игровой движок
│   └── input_handler.py   # Обработка ввода
├── entities/              # Игровые сущности
│   ├── player.py          # Игрок (N7 боец)
│   ├── enemy.py           # Враги (Жнецы)
│   └── bullet.py          # Пули
├── systems/               # Системы логики
│   ├── movement.py        # Движение
│   ├── collision.py       # Коллизии
│   ├── combat.py          # Боевая система
│   └── wave.py            # Система волн
└── states/                # Состояния игры
    ├── menu_state.py      # Главное меню
    ├── game_state.py      # Игровой процесс
    └── game_over_state.py # Экран смерти
```

## Текущий статус (MVP)

✅ Реализовано:
- Движение игрока (WASD)
- Перекат (SPACE) с кулдауном
- Стрельба в направлении мыши
- Базовый ИИ врагов (преследование)
- Система волн со спавном
- Коллизии (пули-враги, враги-игрок)
- HP бар и счет
- Главное меню и экран Game Over
- Перезапуск после смерти

🔄 В разработке:
- Магазин/терминал
- Инвентарь
- Разные типы врагов
- Таблица рекордов

## Технические детали
- Чистый Python + Pygame
- Без внешних зависимостей (кроме pygame)
- Архитектура на основе систем (ECS-подобная)
- Примитивная графика (квадраты/круги) для прототипа
